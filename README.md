# Projeto-Integrador-Controle-de-Materiais
Este trabalho
apresenta o desenvolvimento de um sistema computacional em linguagem Python voltado ao
registro de coletas seletivas, organização de solicitações pendentes e geração de relatórios
gerenciais para administração condominial. A metodologia adota uma abordagem aplicada
fundamentada nas disciplinas de Lógica de Programação e Estrutura de Dados, implementando
estruturas de registros em dicionários, listas dinâmicas, persistência de dados em formato JSON,
fila do tipo FIFO (First-In, First-Out) para atendimento de solicitações de moradores, matrizes
bidimensionais para consolidação mensal por tipo de material, algoritmos manuais de ordenação
(Bubble Sort e Selection Sort), pesquisas sequencial e binária, além de funções recursivas e
rotinas de validação de entrada. Os resultados demonstram que o software elimina a perda de
histórico, automatiza o cálculo de peso médio, identifica a maior e a menor coleta e emite alertas
automáticos ao atingir a meta de armazenamento de 100 kg
